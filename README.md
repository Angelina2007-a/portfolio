# Angelina Raj — Premium AI/ML & Research Portfolio

An award-quality, highly animated, dark editorial portfolio built for **Angelina Raj** (AI/ML Engineer & Research Enthusiast).

## Color System
Inspired by deep space & quantum ocean color palette:
- **Deep Background**: `#020617` / `#03045E` (Deep Space Navy)
- **Panel Background**: `#070F2B`
- **Cards & Components**: `#0C1736`
- **Primary Accent**: `#00B4D8` (Vibrant Electric Cyan)
- **Secondary Accent**: `#0077B6` (Cerulean Blue)
- **Highlight Text**: `#90E0EF` & `#CAF0F8`

## Features & Sections
- **Hero Section**: Dramatic editorial layout featuring framed portrait cutout with tech scanlines, live HUD stats, and custom cursor glow.
- **Fixed & Mobile Navigation**: Sticky glassmorphic navbar with smooth scroll links and a mobile drawer menu.
- **Desktop Social Rail**: Fixed vertical rail with quick tooltips for GitHub, LinkedIn, and Email.
- **Editorial About Section**: Focus area grid highlighting AI/ML, Scientific Research, Computer Vision, and IoT/Cloud.
- **Selected Projects Grid**: 9 key interactive projects (Terraflow, Smart MediTriage-AI, KubeScaleAI, Rice Seed Classification, QUBO-QAOA, AI HVAC, Predictive Infrastructure, Gemini Image Editor, IoT Surveillance).
- **Interactive Detail Drawer Modal**: Clicking any project card opens a comprehensive detail view (Problem, Approach, Tech Stack, Outcome, GitHub link).
- **Technical Toolkit**: Skill cards categorizing Programming, AI/ML, Cloud/DevOps, Embedded/IoT, Algorithms, and Web with status tags (`CORE`, `WORKING`, `EXPLORING`).
- **Research & Career Direction**: Dynamic HTML5 Canvas rendering interactive AI neural nodes and signal trajectories.
- **Timeline**: Vertical milestone timeline with glowing nodes.
- **Resume & Certificates**: Connected directly to `assets/Angelina_A_Resume.pdf`.
- **Contact Form**: Real-time validated contact form with success feedback toasts.

## Project Structure
- `index.html` — Full HTML5 semantic document
- `style.css` — Custom design system, typography scale, animations, and responsive breakpoints
- `script.js` — Interactive project modal engine, ambient node canvas, cursor follower, and form validator
- `assets/` — `hero.png`, `Angelina_A_Resume.pdf`

## How to Run
Simply open `index.html` in your web browser or run a local HTTP dev server (e.g. `npx serve .` or VS Code Live Server).
